Become an observer

An observer listens to the mesh and forwards every packet it hears to the FWA Mesh analyzer over MQTT, so the whole community can see coverage, paths, and gaps. It doesn't change how your repeater behaves on the air.

What you need

  • A MeshCore repeater (or observer) running firmware built with MESH_PACKET_LOGGING=1. LetsMesh token auth (optional, below) needs v1.8.0 or newer.
  • An always-on Linux or macOS machine (a Raspberry Pi is fine) with Python 3.11+, connected to the repeater over USB.
  • Internet access from that machine to mqtt.fwamesh.net port 1883.

Setup with meshcoretomqtt

  1. Install meshcoretomqtt on the machine attached to your repeater: 
    curl -fsSL https://raw.githubusercontent.com/Cisien/meshcoretomqtt/main/install.sh | sudo bash
  2. Create /etc/mctomqtt/config.d/99-user.toml: 
    [general]
iata = "FWA"               # your area's code from the list above

[serial]
ports = ["/dev/ttyACM0"]   # or /dev/ttyUSB0

[[broker]]
name = "fwamesh"
enabled = true
server = "mqtt.fwamesh.net"
port = 1883
transport = "tcp"

[broker.tls]
enabled = false

[broker.auth]
method = "none"
  3. Restart the service: sudo systemctl restart mctomqtt, then check it with journalctl -u mctomqtt -f.
  4. Within a few minutes your observer should appear on the observers page under your region code.

Also feeding LetsMesh?

You can publish to FWA Mesh and LetsMesh at the same time. Add a second [[broker]] block to the same file:

[[broker]]
name = "letsmesh-us"
enabled = true
server = "mqtt-us-v1.letsmesh.net"
port = 443
transport = "websockets"

[broker.tls]
enabled = true

[broker.auth]
method = "token"
audience = "mqtt-us-v1.letsmesh.net"

Hiding your node: rename it to start with 🚫 and send an advert. It will be hidden from this site's map and node list.

When other means fail, the mesh still carries the message.
