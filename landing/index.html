Off-grid messaging, built by Fort Wayne neighbors.

MeshCore is an off-grid messaging and telemetry network that keeps working when the internet and cell service don't. Small, low-power LoRa radios pass messages from node to node. There are no towers, no subscriptions, and no single point of failure. FWA Mesh is the Fort Wayne window into that network: a live map and packet analyzer fed by local observers, supporting the NEIMesh co-op that's building coverage across Northeast Indiana.

      How it grows

      A network the community carries, one node at a time.

      Nobody owns this network, and that's the point. Every radio someone puts on the air relays for everyone else, so each new node makes the whole mesh a little stronger. Neighbors, ham operators, and tinkerers are building it out together: Allen County first, then the rest of the northeast Indiana counties.

      Listen and talk

      Pick up an inexpensive companion radio, pair it with your phone, and join the local chat. Every companion that shows up helps prove where coverage reaches.

      Add a repeater

      Repeaters are the backbone. Anyone can add one; it doesn't have to be owned or managed by anybody else. High spots such as rooftops, towers, and water towers make the biggest difference.

      Use the same settings

      A shared mesh only works if everyone is on the same radio settings. Match the recommended settings so your node can hear and relay everyone else's.

      Feed the map

      An observer forwards what its radio hears to this site, so everyone can see coverage, paths, and gaps. More observers in more places give us a truer picture. Run an observer →

      Across Indiana

      HOOP: the statewide signpost.

      HOOP, the Hoosier Off-Grid Open Playbook, is a community-built guide to off-grid radio in Indiana: MeshCore, Meshtastic, GMRS, ham radio, and Reticulum. Instead of inventing its own rules, it gathers settings, nets, maps, and projects from the people and projects that maintain each one, links every item to its source, and refreshes its data automatically. It's open source, and contributions and forks are welcome.

      Get started

      Get on the mesh in an afternoon.

      Get a radio

      Almost any MeshCore-compatible LoRa board for the US 915 MHz band works: Heltec V3 or T114, RAK WisBlock (great for solar repeaters), Seeed T1000-E, and more. See mesh gear for boards, antennas, and solar parts we recommend.

      Flash MeshCore

      Use the MeshCore web flasher. Choose Companion for a personal radio or Repeater for a fixed high site, then apply the settings below.

      Say hello

      Send an advert, then join #nei and say hi. If an observer hears you, your node shows up on the nodes page within a few minutes.

      Recommended settings

      Same settings, one network.

      These follow NEIMesh's recommended node settings so every node in the area can talk to every other. They may change as the network grows. NEIMesh.net always has the current list.

      Radio

      PresetStandard USA / Canada
      Frequency910.525 MHz
      Bandwidth62.5 kHz
      Spreading factor7
      Coding rate5
      Path hash size2-byte

      Repeaters

      Recommended CLI settings:

      set agc.reset.interval 500
set multi.acks 1
set loop.detect minimal

      Region settings. These aren't enforced yet, but the Fort Wayne weather-alert bot already scopes messages to fwa:

      region put us-in
region put nei us-in
region put fwa nei
region allowf *
